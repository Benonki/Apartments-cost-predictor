# Apartments cost analyser App

A Python-based application for analyzing and predicting apartment prices in Poland, helping users explore price trends, compare locations, and understand the factors affecting real estate prices.

## 📈 Dataset

**Dataset**: `Apartment Prices in Poland`

**Author**: Krzysztof Jamroz

**Source**: Kaggle

## ⚙️ Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Benonki/Apartments-cost-predictor.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
   - If you update the project, refresh `requirements.txt`:
     ```bash
     pip freeze > requirements.txt
      ```

## 🚀 Running the App

1. Run `csv_to_db.py` script:
   ```bash
   python csv_to_db.py
   ```
2. Start the desktop app:
   ```bash
   python main.py
   ```
